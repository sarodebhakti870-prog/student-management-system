# 🎓 Student Management System

A simple and user-friendly **Student Management System Website** developed using HTML, CSS, and JavaScript.

## 📌 About the Project

The Student Management System is a web-based application designed to manage and display student information in an easy and organized way.

This project provides a simple interface that can be used to manage student records and demonstrate basic web development concepts.

## 🚀 Features

- 👨‍🎓 Student information management
- ➕ Add student details
- ✏️ Update student information
- 🗑️ Delete student records
- 🔍 View student details
- 📱 User-friendly interface
- 🎨 Responsive and attractive design
- ⚡ JavaScript-based functionality

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and layout
- **JavaScript** – Functionality and interaction
